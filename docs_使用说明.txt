云朵小铺 · FYS 通关奖励看板
============================

【这是什么】
读取 fys 官方客户端写出的广播文件 + 風雲社官网公开数据，实时显示你当前所在服务器的
地图、关卡，以及该关的通关云点 / 通关龙晶奖励与伤害达标门槛。
附带：屏幕覆盖小窗、5 套主题 + 5 套可切换界面背景 + 侧栏贴纸、地图库（关键词 / 分类筛选）、
关卡明细弹窗、地图实体预览（3D：传送门 / 触发区 / 可破坏物 / 机关，含真实碰撞地形，
软件内直接打开；另有「🪟 独立窗口」模式，可最大化、拖到第二块屏）。

【怎么用】
1. 保持 FYS-Reward.exe 与 _internal 文件夹在一起（目录式免解压），
   双击 FYS-Reward.exe 启动；启动期间先看到云朵小铺启动卡，几秒后进主界面
2. 进游戏即可，不用手动操作：软件会自动定位你所在的服务器与地图
3. 想让它一直显示在屏幕上 → 左侧「屏幕覆盖」页打开开关
4. 想看地图长什么样 → 左栏「🗺️ 地图实体预览」软件内直接看（离开该页自动释放渲染）；
   地图库选图后也能点「🗺️ 地图实体预览」直达这张图；觉得卡点页内「🪟 独立窗口」。
   预览页与 857 张图的真实碰撞地形**不再打进精简包**：第一次点开「地图实体预览」
   会自动下载预览数据（约 14.7MB，视网速 10~40 秒，有进度条），点开某张图再下该图的
   地形（中位 0.4MB）；下过就缓存在本地，之后离线也能看。想一次到位、不联网也能看，
   请下「全量版」压缩包（预览页与全部地形都随包）。

【对局战绩 + CS2 游戏状态集成（GSI）】
· 对局战绩在「屏幕覆盖 → 📊 战绩」分栏：进服打一局，换图或本局结束会自动记一条
  （地图 / 关卡 / 比分 / 时长 / K-D-A / 本局伤害），数据只存本机 data\matches.json
· **默认开启**：软件启动时自动把 GSI 配置写进 CS2 目录，写完后**必须重启一次 CS2** 才会加载
  （游戏只在启动时读 GSI 配置；如果先开游戏再开软件，界面会明确提示「需要重启 CS2」）；
  不想用就在该分栏点右侧开关关掉（关掉即删除配置，之后不再写）；换端口/重装游戏点
  「↻ 重写配置」即可
· 地图与比分**直接来自游戏本身**（GSI 官方机制），比广播文件 + 服务器查询更准；
· 伤害 = 每回合 round_totaldmg 的峰值累加（GSI 只给本回合伤害，回合结束清零）；
  「云点 / 龙晶兑换」按该图该关官方配置的伤害转化比（伤害 : 1 货币）向下取整，
  仅供参考，实际以服务器结算为准；显示为「本关 X 云点 / Y 龙晶」的是该关标准值
· 覆盖小窗直接联动本局伤害（需要开启 GSI）：
  「通关云点 13（1↑）」括号里是本局伤害换到的云点个数，0 也显示；
  「伤害云点 2.4w（0.3w）」括号里是距下一档兑换还差多少伤害
  （例：本局 2.1w、门槛 2.4w → 还差 0.3w；本局 2.5w → 还差 2.3w）
· 「屏幕覆盖」页分三栏：外观与内容 / 直播输出 / 战绩；对局战绩也在这一页查看，
  左侧菜单不再单独占一条

【运行环境】
· 软件固定用本机端口 8777 提供服务（GSI 配置、OBS/浏览器地址因此固定不变）；
  8777 被别的程序占用时会自动换一个随机端口，实际端口在「设置 → 关于 → 服务端口」里看；
  重复双击不会开第二个实例：会把已经开着的那个窗口直接叫到前台（最小化也会还原）
· Windows 10 / 11（64 位）
· 无需安装 Python，地图数据已内置，不联网也能看数值
· 3D 预览页与地形都**按需下载**：首次点开「地图实体预览」先下预览数据（约 14.7MB，
  有百分比进度条，失败可点「🔄 重新加载」）；地形第一次点开某张图才下（中位 0.4MB），
  之后缓存在 terr\ 里离线也能看。下载源是 GitHub 托管（gh-proxy / jsDelivr / 直连
  多源自动切换，开着代理（VPN）也会自动走代理）；全量版压缩包已内置这两样
· 服务器状态由本机直接查询游戏服务器得到（不经中转），个别服维护时会显示离线
· 界面用系统自带的 WebView2（Win11 自带；Win10 若提示缺失，装个 Edge 就好）

【数据与更新】
· 首次运行会把内置数据释放到 exe 同目录的 data\ 文件夹
· 新图上线 / 官方改参数后想更新 → 「设置」页点「立即同步」（直连 GitHub 官方仓库，
  约 3~10 秒；开着「自动同步」时软件会自己检测并应用；失败不影响现有数据）
· 新图封面不用等版本更新：每次同步完成后软件会自动连风云社官方图床
  （resx.fyscs.cn）把本地缺的封面补下来，存进 exe 同目录的 cover\（约 10KB/张）
· 地图译名随包分发（1400+ 条，含官方表与 EXG 补充表），不联网也有中文名
· 想看 3D 地形占了多少磁盘 → 「设置」页「地形分包」一行有占用统计与「🧹 清理」
  （⚠ 本版无云端源，清理后不能自动恢复，只能重新解压完整压缩包，一般不建议清）
· data\ 里都有啥：
    rewards.json          通关奖励（云点 / 龙晶，按关卡）
    maps.json             地图参数（管理员 / 提名 / 时段 / 价格 / 冷却）
    infect.json           尸变参数（随机尸变 / 母体比例 / 倒计时）
    knockback.json        击退系数
    platform_mapnames.json 官方中文译名
    startup.log           运行日志（超过 512KB 自动归档为 startup.old.log）

【常见情形】
· 显示「未在服务器内」→ 还没进服，或 CS2 没运行
· 显示「关卡待同步」→ 已认到地图但没读到关卡号，数值先按第 1 关显示，下表可查全部关卡
· 认不出地图 → 「设置」页最下方有「广播文件原文」，把内容发给分享给你的人即可补规则
· 窗口打不开 / 白屏 → 删掉 data\startup.log 后重试；仍不行就把该日志发出来
· 实体预览打不开 / 一直停在下载 → 首次需要下约 14.7MB 预览数据，进度条会走动；
  失败了点遮罩里的「🔄 重新加载」，多次失败就检查网络或代理（软件会自动走系统代理）
· 3D 视图提示「地形下载失败」→ 检查网络（地形是按需从托管下载的），重开该图会重试；
  「地形未收录」= 这张图还没生成地形，等下次版本更新
· 精简包 27MB（不含预览页与地形，点开时自动下载并缓存）；全量版 316MB 把预览页
  与 857 张地形都打包在内，解压后即离线可用（不用再等下载）

【启动报「无法完成操作，因为文件包含病毒或潜在的垃圾文件」】
这是 Windows Defender 的**误报**，不是真的有毒。本软件是 Python 打包的单文件程序，
运行时要先把内置数据解压到临时目录再启动 —— 这个「自我解压」行为和某些病毒很像，
杀软经常不问青红皂白就拦。软件没有签名证书（要花钱买），所以更容易被拦。

按下面的顺序试，一般第 1 步就能解决：

1) 把软件文件夹加进 Defender 白名单（推荐，一次搞定）
   · 右键开始菜单 → 「终端(管理员)」或 PowerShell(管理员)
   · 复制粘贴下面这行，把路径换成你自己的文件夹后回车：
       Add-MpPreference -ExclusionPath "C:\你的路径\云朵小铺-FYS通关奖励看板"
   · 没报错就是成功了，重新双击 exe 即可
   （想撤销：Remove-MpPreference -ExclusionPath "C:\你的路径\云朵小铺-FYS通关奖励看板"）

2) 不想加白名单：临时放行一次
   Windows 安全中心 → 病毒和威胁防护 → 「保护历史记录」→ 找到被隔离的那条
   → 点「允许在设备上」或「还原」，再从隔离区把 exe 恢复回来。

3) 其它杀软（360 / 火绒 / 腾讯管家 / 迈克菲…）
   同样在「信任区 / 白名单 / 例外」里把 exe 或整个文件夹加进去。
   火绒：设置 → 安全设置 → 信任区；360：设置 → 白名单。

4) 还是不行：从官网直链重新下一次（有些网络工具会在下载途中改写文件，
   改过的文件更容易被判可疑）：
       http://124.223.107.6/update/FYS-Reward.exe

· 顺带一提：软件每次发版都会向微软提交误报申诉，通常几天内 Defender 就不再报了。
  如果你现在还在被拦，用上面第 1 步先跑起来就行 —— 那只是本地的拦截规则，
  不影响软件本身。

【界面背景】
· 「主题」页的「🖼 界面背景」有 5 套可切换：云朵小铺（默认）/ 冒险出发 / 通关庆祝 /
  二次元日常 / 纯色无背景；点击即换、自动记住，想清爽点到纯色即可全部关掉
· 云朵小铺那套是主题图案铺底（云朵 / 龙晶 / 小僵尸）+ 服务器页与地图库顶部插画横幅 +
  设置页头图 + 侧栏小僵尸贴纸 + 卡片云朵角标；另外几套把插画当整幅氛围底
· 底纹自动跟随明暗：切到「夜幕护眼」主题时图案换成暗色版、插画自动压暗，不刺眼
· 换花眼了？「主题」页底部有「↺ 恢复默认外观」，主题 / 背景 / 贴纸一键回出厂

【侧栏贴纸】
· 「主题」页的「🧸 侧栏贴纸」可选：云朵精灵 / 小白猫（默认）/ 小僵尸 / 不显示，
  点击即换、自动记住；贴纸固定在左侧栏底部，不影响其它内容

【一键更新】
· 软件启动时会自动检查新版本，之后每 15 分钟再自动查一次（软件开着几天也能收到
  新版提示）；有新版时「设置 → 更新日志」上方会亮出绿色横幅
  「发现新版本 vX.Y — 一键更新」，点一下即自动下载、校验并重启（下载有真实进度
  百分比，失败会自动重试一次，约 1 分钟，视网速）
· 更新只替换软件本体，你的 data\ 偏好与记录不受影响；没有新版时横幅不会出现

【参数小抄】
· 关卡表 / 地图库里的伤害数值是「达标门槛」：每造成该数值伤害，额外 +1 云点或龙晶
  （例：门槛 3w → 每打满 3 万伤害 +1），鼠标悬停可看原始数值
· 地图库里 🔑 需管理员 · 🎲 随机尸变 · 🕒 限定时段 · 🌐 全天可玩
· 地图库每一行都铺着这张地图的真实封面做底纹（左实右透，不挡文字与徽标），
  当前服务器在玩的那张一眼就能认出来；官方图床没收录的图不会显示破图，只有底色
· 地图库收藏：点列表行尾的 ☆（或详情页「☆ 收藏」按钮）收藏常用图，收藏的图
  永远排在最前，分类里的「⭐ 我的收藏」一键筛出全部收藏；收藏存在本机不丢失
· 有新版本时打开软件会弹更新提示窗：点「立即更新」直达下载进度；
  点「稍后再说」同一版本不再弹（设置页更新日志上方的横幅常驻，随时可更新）
· 快捷操作：侧栏可收起；覆盖小窗可直接拖动摆位置（拖到哪，下次就在哪打开）；
  「屏幕覆盖」页可勾选「鼠标穿透」——开启后鼠标点击直接穿过小窗落到游戏，
  小窗不再响应点击与拖动，要移动或关闭就回该页面取消勾选（切换立刻生效，
  不用重启小窗）；覆盖设置页的「分区」点标题即可展开 / 收起，状态会记住；
  地图库搜索框按 ⏎ 回车直接打开第一条结果，弹窗按 Esc 关闭；
  主窗口点最小化会收到系统托盘（点托盘图标还原，右键托盘可显示主窗口或退出）
· 窗口大小：拖窗口的边沿或四个角就能放大缩小；右上角圆点按钮是最小化 / 最大化 /
  关闭，双击标题栏也能最大化与还原；点最小化会收到系统托盘（托盘图标常驻：
  左键点击还原主窗口，右键菜单可「显示主窗口 / 退出」），不占任务栏
· 实体预览：软件内打开，左键旋转 / 右键平移 / 滚轮缩放，T 俯视 R 复位；
  自由视角（🕊）移速用右上面板「移速」滑杆调（自动记忆），行走模式滚轮调速；
  图层面板单击切显隐、双击独显某层；右上面板可分层、剖切、调块体透明度；
  低频选项（区域光晕 / 全范围 / 适应窗口 / 导出 PNG 等）收进右上角「⋯ 更多」菜单；
  3D 地形颜色与雾气跟随软件主题变化
  （643 张图带从创意工坊地图包解析的真实碰撞地形，首次打开该图时云端下载）。
  关卡 / 实体数据在首次打开预览时下载一次，之后就是本地快照；
  只有没下载过的图需要联网
